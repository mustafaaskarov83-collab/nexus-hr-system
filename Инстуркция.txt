Ритуал обновления (запомни!)
Теперь, каждый раз после того как мы доработаем код:

Шаг 1. Обнови файл в корне
Скопируй новый файл из 01-current\nexus-hr.html

Вставь в корень NEXUS-HR\ заменяя старый index.html

Или просто переименуй копию в index.html

Шаг 2. GitHub Desktop
Открой GitHub Desktop

Увидишь изменённый index.html

Summary: напиши что изменилось (например, v3.3 — добавлены больничные)

Commit to main

Push origin

Шаг 3. Обнови страницу сайта
Через 1–2 минуты открой ссылку заново или нажми Ctrl+F5.

Всё. Сайт обновится автоматически. Никаких серверов, FTP, развёртываний.

⚠️ Важные нюансы
Про данные на сайте
localStorage — отдельно для каждого браузера и устройства. Это значит:

На твоём компьютере — одна база данных (с твоими сотрудниками)

На телефоне — пустая (нужно заново создать admin)

У коллеги — своя

Синхронизации между устройствами нет. Если нужна — это уже следующий уровень (Firebase, Supabase, свой сервер). Обсудим, если понадобится.

Про бэкапы
Раз в неделю заходи в приложение и делай:
Експорт JSON → файл сохраняй в 03-backups\
Это твоя страховка от потери данных.

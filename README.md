\# NEXUS ENGENEERING — HR System



Система кадрового учёта с расчётом отпусков по законодательству Украины.



\## Возможности



\- Авторизация с ролями (admin / manager / viewer)

\- Учёт сотрудников с категориями

\- Расчёт отпускных (Порядок №100)

\- Компенсация при увольнении

\- Импорт/экспорт Excel

\- Три языка: УКР / РУС / TÜR



\## Технологии



\- HTML5 + CSS3 + Vanilla JavaScript

\- localStorage для данных

\- SheetJS для Excel



\## Как запустить



Откройте файл `01-current/nexus-hr.html` в браузере.



При первом запуске создайте администратора (логин `admin`, пароль на ваш выбор).



\## Структура



\- `01-current/` — текущая рабочая версия

\- `02-versions/` — архив версий

\- `03-backups/` — JSON-бэкапы данных

\- `04-notes/` — заметки
